---
name: exam-questions
description: Write multiple choice questions for
  quizzes and exams from the lecture slides
---

- Only use content covered in the slides
- Ask "Which statements about ... are true?"
- Give 5 statements, any number of them true
- Make wrong statements plausible, e.g. a
  swapped term or a reversed effect
- Add one line explaining each answer
- Output LaTeX in the format of
  int/exams/example-questions.tex
